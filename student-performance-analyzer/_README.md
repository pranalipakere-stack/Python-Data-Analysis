# Student Performance Analyzer

## Project Overview

This project analyzes student academic performance using Python and Pandas.

## Tools Used

- Python
- Pandas
- Matplotlib

## Analysis Performed

- Calculated total marks
- Calculated average marks
- Identified highest and lowest performers
- Created Pass/Fail results
- Analyzed subject-wise performance
- Analyzed attendance and marks
- Created visualizations

## Key Insights

- Anjali achieved the highest average score of 95.0.
- Science had the highest subject average of approximately 77.53.
- All 15 students passed the defined pass criteria.
- Higher attendance generally appears to be associated with better average marks.
- Overall, the dataset shows good student performance.

## Visualizations

1. Average Marks by Student
2. Average Marks by Subject
3. Attendance vs Average Marks

## Conclusion

The project demonstrates how Python and Pandas can be used to analyze student performance and extract meaningful insights from data.
